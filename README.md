# 국방예산 및 중점사업 대시보드 (Web Dashboard)

이 웹 애플리케이션은 **국방예산 정부안 중점사업** 형태의 엑셀(.xlsx, .xls) 또는 CSV 파일을 입력받아 **분야별**, **신규사업별** 핵심 지표와 상세 사업 내역을 직관적으로 시각화 분석하는 인터랙티브 대시보드입니다.

---

## 📁 주요 구성 파일

- [`index.html`](file:///c:/work1020/web/index.html): 대시보드 메인 웹페이지 (브라우저에서 더블클릭 또는 웹서버로 즉시 구동 가능)
- [`css/style.css`](file:///c:/work1020/web/css/style.css): 반응형 레이아웃, 라이트/다크 모드, 모던 글래스모피즘 테마 스타일
- [`js/app.js`](file:///c:/work1020/web/js/app.js): 상태 관리, 드래그&드롭, 파일 업로드, 탭 전환, 실시간 검색/정렬, 모달 제어
- [`js/parser.js`](file:///c:/work1020/web/js/parser.js): 엑셀(XLSX) 및 CSV 유연한 컬럼 매핑, 수치 정규화, 신규사업 자동 판정 엔진
- [`js/charts.js`](file:///c:/work1020/web/js/charts.js): Chart.js 기반 도넛, 그룹바, 수평바, 파이 차트 시각화 모듈
- [`js/defaultData.js`](file:///c:/work1020/web/js/defaultData.js): 2027년 국방예산 정부안 중점사업 기본 데이터셋 (22개 사업)
- [`lib/xlsx.full.min.js`](file:///c:/work1020/web/lib/xlsx.full.min.js): 오프라인 구동을 위한 SheetJS 라이브러리 (로컬 번들)
- [`lib/chart.umd.min.js`](file:///c:/work1020/web/lib/chart.umd.min.js): 오프라인 구동을 위한 Chart.js v4 라이브러리 (로컬 번들)
- [`sample_template.xlsx`](file:///c:/work1020/web/sample_template.xlsx): 입력 양식 표준 엑셀 파일
- [`sample_template.csv`](file:///c:/work1020/web/sample_template.csv): 입력 양식 표준 CSV 파일

## 🚀 주요 기능 및 특징

1. **엑셀 & CSV 드래그 앤 드롭 및 업로드**
   - 브라우저 어디서나 파일(.xlsx, .xls, .csv)을 끌어다 놓거나 상단 [📁 엑셀/CSV 업로드] 버튼 클릭
   - 컬럼명이 약간 다르거나 서식이 달라도 지능형 컬럼 감지기를 통해 자동 매핑
   - 파일 로드 시 모든 KPI와 4개 탭의 차트 및 테이블이 실시간 갱신

2. **상단 핵심 KPI 카드**
   - 2027년 정부안 총 예산 (2026년 본예산 대비)
   - 전년 대비 순 증감액 및 증가율
   - 신규 사업 건수 및 신규 사업 총 편성액
   - 최대 투자 중점 분야 및 예산 규모
   - 등록 사업 현황 (기존 사업 vs 신규 사업 건수)

3. **4대 분석 탭 구성**
   - **📊 종합 대시보드 (Overview)**: 분야별 2027년 예산 비중(도넛), 전년 vs 당해년도 비교(그룹바), 증감액 순위(수평바), 기존 vs 신규 비중(도넛), 최대 증액 Top 3 및 최고 증가율 사업 하이라이트
   - **🏷️ 분야별 심층 분석 (Sector Deep-Dive)**: 8대 중점 분야별 탭 필즈(Pill Selector), 선택 분야 총액·증감·사업수 요약, 분야 내 세부 사업별 비교 차트 및 상세 카드 그리드
   - **🚀 신규사업 전용관 (New Projects Spotlight)**: 2027년 신규 편성된 사업만 집중 조명, 신규사업 규모 순위 차트, 신규사업 분야별 투자 분포 차트, 보도자료 원문 근거가 포함된 전용 카드
   - **📋 전체 데이터 탐색 (Data Explorer)**: 실시간 검색(사업명, 분야, 원문 내용), 분야별 필터, 사업유형별 필터(전체/신규/기존), 컬럼별 정렬(오름차순/내림차순), 행 클릭 시 상세 모달, CSV 및 Excel 내보내기 기능

4. **100% 오프라인 구동 지원 & 다크모드**
   - 인터넷 연결이 없는 환경에서도 로컬 라이브러리(`lib/`)를 통해 완벽 구동
   - 우측 상단 달/해 아이콘을 통한 원클릭 라이트/다크 모드 전환 (차트 색상 실시간 연동)
